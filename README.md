# B3PZ Games

Raccolta di 11 giochi indipendenti di B3PZ, con copertine scorrevoli e filtri per genere.

## Sito
https://b3pz.github.io/B3PZ-Games/

## Struttura
- index.html: pagina e contenitore dei giochi.
- style.css: stile e layout responsive.
- app.js: catalogo, filtri, carosello e apertura dei giochi.
- assets/: immagini ottimizzate per le custodie.

I giochi vengono caricati dalle rispettive pagine GitHub Pages. Tornare alla raccolta chiude il gioco dopo un avviso; i progressi dipendono dal sistema di salvataggio del singolo titolo.

Per modificare la raccolta aggiorna il catalogo in app.js. Per provarla in locale: python3 -m http.server 8000.

Le copertine attuali sono provvisorie. Mimmo Express è un progetto personale ed è escluso dal catalogo.
