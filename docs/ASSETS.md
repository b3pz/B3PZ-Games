# Copertine e screenshot

Le illustrazioni delle copertine sono create per questa raccolta. I loghi sono quelli originali dei giochi: file grafici delle rispettive repository oppure porzioni della grafica originale mostrate senza ridisegnare il titolo.

Le scritte alternative presenti nei file di illustrazione generati non sono mostrate: la fascia inferiore delle custodie mostra il logo originale.

## Screenshot
Catture reali delle pagine di gioco effettuate il 26 ottobre 2026, senza ricostruzioni generate. Le didascalie distinguono menu, selezione e gameplay. Nessuna immagine generata è presentata come screenshot.
